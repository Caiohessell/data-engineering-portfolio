# 🧠 Análise da Saúde Mental de Estudantes

## 📖 Sobre o projeto

Este projeto investiga fatores associados aos níveis de depressão em estudantes universitários por meio da análise exploratória de dados utilizando SQL.

O objetivo é identificar padrões e possíveis associações entre características demográficas, acadêmicas e sociais, transformando dados brutos em insights que apoiem a compreensão do cenário estudado.

Durante o desenvolvimento são aplicadas práticas comuns em projetos de Análise de Dados, desde a avaliação da qualidade dos dados até a comunicação dos resultados por meio de visualizações.

---

## 🎯 Objetivo

Responder perguntas de negócio relacionadas à saúde mental dos estudantes utilizando SQL para explorar os dados, identificar padrões e gerar insights.

---

## 🔍 Metodologia

O projeto é desenvolvido em quatro etapas:

- **Limpeza dos dados:** avaliação da qualidade da base e identificação de valores nulos.
- **Análise Exploratória (EDA):** compreensão da distribuição dos dados e identificação de padrões iniciais.
- **Análise de Negócio:** resolução de perguntas analíticas utilizando recursos do SQL, como funções de agregação, `GROUP BY`, `HAVING`, `CASE`, subqueries e CTEs.
- **Visualização dos Dados:** construção de um dashboard no Power BI para comunicar os principais resultados.

Ao longo do projeto são aplicados conceitos fundamentais de Análise de Dados, incluindo:

## 📌 Observação

Este projeto faz parte do meu portfólio de Análise de Dados e tem como objetivo demonstrar a aplicação de SQL em um fluxo completo de exploração, tratamento e análise de dados. As conclusões obtidas representam associações observadas no conjunto de dados e não estabelecem relações de causalidade.
